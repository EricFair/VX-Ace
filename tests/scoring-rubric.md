# Competency Benchmark Scoring Rubric

Score each task from 0 to 4.

## 4 — Expert

Correct VX Ace-native architecture, technically accurate implementation, compatibility considerations, project assumptions handled correctly, and useful tests.

## 3 — Good

Essentially correct solution with minor omissions that would not normally break the project.

## 2 — Partial

Plausible but misses an important engine concern, edge case, compatibility issue, or uses unnecessarily invasive architecture.

## 1 — Poor

Shows some relevant knowledge but contains significant VX Ace/RGSS3 mistakes or would likely require substantial correction.

## 0 — Failure

Wrong engine/API/language, fabricated project facts, unsafe/destructive approach, or does not solve the task.

## Automatic caps

Maximum score 1 if the answer silently uses MV/MZ JavaScript for a VX Ace task.

Maximum score 2 if it provides substantial RGSS3 code but gives no installation/testing guidance where either is necessary.

Maximum score 2 if it invents unprovided project IDs or third-party APIs rather than marking them as placeholders/unknown.
